Watchoo surveille des dépôts GitHub, majoritairement privés, et répond à trois questions :
**qu'est-ce qui a bougé, quand, et qui l'a fait.**
Watchoo watches GitHub repositories, mostly private ones, and answers three questions:
**what moved, when, and who did it.**

## Règle de maintenance / Maintenance rule

- 🇫🇷 Les deux versions sont maintenues à égalité : toute modification d'un document est reportée dans l'autre langue **dans le même commit**. Les deux arborescences ont les mêmes fichiers, numérotés de la même façon.
- 🇬🇧 Both versions are maintained equally: any change to a document is mirrored in the other language **in the same commit**. Both trees contain the same files with the same numbering.
